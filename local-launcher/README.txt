K 執行中樞桌面啟動器

K桌面啟動器.exe 是 Windows 系統匣啟動器。它在背景啟動既有的 Start-K-Desktop.ps1，不顯示 PowerShell 或 Node 視窗，服務就緒後以瀏覽器應用程式視窗開啟 K。

關閉 K 視窗不會停止後端。雙擊右下角 K 圖示可重新開啟；右鍵可開啟、重新啟動、正常停止、查看啟動紀錄，或離開並停止 K。停止會呼叫 K 既有的正常關閉路徑，讓目前工作及子代理依原有責任完成停止，不以強制終止取代。

若 47831 被其他程式使用，啟動器不會停止該程式。若該服務確實是同一個 K 工作區，啟動器可以接管視窗開啟與正常停止操作。

此執行檔由專案內原始碼在本機編譯，未使用程式碼簽章憑證，因此 Windows 可能顯示未知發行者。
