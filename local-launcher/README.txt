K 執行中樞桌面啟動器

K桌面啟動器.exe 是 Windows 系統匣啟動器。它啟動 K 隔離執行環境，不顯示 PowerShell 或 Node 視窗，服務就緒後顯示 Electron 原生 K 視窗。右側為真正可直接點擊、輸入、捲動的網頁，不是定時截圖；人工接手時暫停 AI 的瀏覽器操作，交回後使用同一頁面。新版正式啟動及驗收狀態見 docs/native-browser-release-20260926.md。

桌面捷徑可呼叫專案根目錄的 `Start-K-Desktop.ps1`；此相容入口只轉交本執行檔，不再啟動一般 host server。若執行檔不存在會停止並提示，不會改走舊後端。舊版 `-NoBrowser` 直接啟後端行為已停用；指定 `-NoBrowser` 會明確回報需由安全啟動器管理。

關閉 K 視窗不會停止後端。雙擊右下角 K 圖示可重新開啟；右鍵可開啟、重新啟動、正常停止、查看啟動紀錄，或離開並停止 K。停止會呼叫 K 既有的正常關閉路徑，讓目前工作及子代理依原有責任完成停止，不以強制終止取代。

若 47831 被其他程式使用，啟動器不會停止或接管該程式；只有目前系統匣啟動器記憶體內持有的控制通道可開啟及正常停止候選服務。

此執行檔由專案內原始碼在本機編譯，未使用程式碼簽章憑證，因此 Windows 可能顯示未知發行者。

2026-09-28 更新：正式入口現使用原生 provider 執行（health deployment=native），不再建立 Sandboxie pool。既有目錄／模組歷史名稱保留，不代表仍啟用外層隔離。權限由各 provider 原生模式處理，既有登入／對話沿用；完整證據見 docs/native-core-permissions-20260928.md。上方舊隔離及內嵌瀏覽器描述不是目前正式執行政策。
