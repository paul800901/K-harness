# K HARNESS

**K 執行中樞｜通用工作台**

這是我自己日常使用的 AI 工作台，現在把原始碼公開，供有興趣的人參考。

它不是面向大眾的產品，也不承諾客服、持續維護、功能排程或適用於每一台電腦。需要的人自行評估、設定與測試；使用時請自行保管帳號與資料，對 AI 的操作和結果負責。

## K 是什麼

在同一個介面交代工作、查看成果、處理核准、停止工作，背後由 **Codex CLI、Claude Code、Antigravity CLI** 各自的原生核心執行。K 是薄接殼，不重做模型執行、對話歷史或壓縮核心，也不把三家的不同能力假裝成完全相同。

沿用各家的原生訂閱登入與權限，不改走另一條 API 計費路徑。需要自行準備可用的官方程式與帳號；本儲存庫不附登入資料、訂閱或額度。

用途是一般文件、資料與程式工作，不接入病歷或 CaseAgent 正式流程。

## 目前的功能

- **三核心聊天**：依本機原生目錄選模型與推理程度；聊天室切換不會停止另一間的背景工作。
- **檔案與圖片**：附檔、預覽、下載，也可只傳圖片或附件、不加文字；完全空白不能送出。模型能否理解檔案仍依各家核心與工具，不是收到原檔就保證能讀。
- **子代理**：GPT／Claude 主聊天室可依已接通的路線派工，模型清單跟隨本機原生目錄；Gemini 主代理的反向派工未提供。必要核准與權限不因派工而放寬。
- **多模型討論**：平行比較、交叉審查、多人討論，保留不同意見；討論本身不取得執行授權。目前帶文字／已擷取文字的文件，圖片影音請用一般對話。
- **工作協調**：待送訊息與編輯、工作中補充、原生活動與工人狀態、目標模式；不因安靜或錯誤自行重播未知工作。
- **工作台**：工作區分組、手動或最近訊息排序、成果查看，以及使用者／助理文字複製。
- **帳號與額度**：沿用原生查詢，標示上次實查；Gemini 可保存本人登入的多個帳號，分別呈現額度，不把未知當零或合併額度。
- **選用功能**：K 專用 Chrome 助手、聽寫成文字、經私人網路使用的手機 PWA。這些需要另外準備本機環境，不是 clone 後就全部可用。

Codex 的容量重試／重連交給原生核心；K 不自動把 Luna 換成 Sol，也不另加一層重送。其他能力差異與驗證限制見[工程紀錄](docs/development-log.md)。

## 安裝、更新與啟動

目前是 Windows 本機工作台。需要 Git、Node.js（至少 22.19）、npm、PowerShell、.NET Framework C# 編譯器，以及本機官方核心執行檔；不提供跨平台或任意環境可用的保證。

```powershell
git clone https://github.com/paul800901/K-harness.git
cd K-harness
$release = '1a45a73440a5f948c5cec625de02340863b7c67d'
```

首次安裝，先確認兩個官方執行檔的實際路徑：

```powershell
.\Setup-K.ps1 -Ref $release -CodexExecutable '<官方 codex.exe 完整路徑>' -ClaudeExecutable '<官方 claude.exe 完整路徑>'
.\Start-K-Desktop.ps1
```

Gemini 另外準備官方 Antigravity CLI，再由本人登入。不要搬另一台的登入、對話、Chrome 設定檔或語音環境。

既有安裝先在 K 選「離開並停止 K」，確認工作結束，再更新：

```powershell
git fetch origin --tags
.\Update-K.ps1 -Ref '1a45a73440a5f948c5cec625de02340863b7c67d'
.\Start-K-Desktop.ps1
```

更新會先準備、建置與測試候選，成功後才替換程式；保留上一版程式與本機設定。不要為更新而覆寫尚未保留的工作樹修改。詳細流程與 Chrome、語音、核心更新步驟見[安裝、更新與退版指南](docs/git-install-update.md)。

## 使用界線

- AI 能呼叫工具，不代表你已授權它操作；仍要自行選擇權限並核對成果。
- 帳號、對話、設定、原始附件、執行紀錄與語音模型留在本機，不隨 Git 發布。
- 程式退版只退程式／啟動器，**不還原對話或工作檔案**；封存不是資料備份。
- 目前不提供對話歷史回溯、工作檔案還原與即時語音對話；聽寫只填草稿，不自動送出。
- 各家訂閱、模型、原生協定與可用能力可能變動；本機使用經驗不是其他環境的保證。
