# K HARNESS

**K 執行中樞｜通用工作台**

K 是供個人使用的 AI 工作台。你在同一個介面交代工作、查看結果、處理核准與停止工作；背後由 Codex 或 Claude Code 執行，沿用各自的官方訂閱與權限，不另改走 API 計費。用途是一般文件、資料與程式工作，不接入病歷或 CaseAgent 正式流程。

## 現在能做什麼

- **交代與接續工作**：選擇工作資料夾、新建或接續對話，附上檔案、查看回覆。可切到另一個聊天室討論，不會因此停止原本的工作。
- **處理檔案與程式**：依你的要求與核准範圍，讓 AI 讀取、建立或修改檔案、執行命令；查看成果、預覽與下載。
- **選擇主代理與子代理**：主代理可選 Codex 或 Claude 的可用模型。GPT 子代理可選 GPT-6.1 Sol 或 GPT-6 Luna；新對話預設由 AI 選擇模型與推理程度，也可手動指定。K 不為「AI 自動選擇」另做品質評估或調校；在意這件事時，請手動指定。
- **瀏覽器協作**：設定 K 瀏覽器助手後，AI 可在 K 專用 Chrome 操作網頁，必要時由你接手登入或驗證。沒有設定助手，也能正常使用文字聊天室。
- **語音輸入文字**：按聽寫直接使用本機 Whisper，不再另跳 K 的啟用同意；停止後將文字放入草稿，由你確認再送出；取消會保留原草稿。這不是即時語音對話。
- **保留必要控制**：工作失敗、額度、登入、核准與需要你決定的訊息會顯示；工程細節留在後台。可停止工作，也可使用右鍵複製、貼上等文字編輯操作。

不同供應商的能力不完全相同，K 不把其中一家的功能說成兩家都有。模型或額度出錯時，不會暗中換模型或重送工作；權限仍以你的選擇與原生核准為準。

## 怎麼啟動、更新與退版

### 啟動

使用既有桌面捷徑開啟 K；或在 K 安裝資料夾執行 `Start-K-Desktop.ps1`。第一次在新電腦使用，需要本人登入官方訂閱並選擇本機工作資料夾，不搬另一台的登入資料。

### 安裝與更新

目前供新電腦安裝的已發布版本是 **`k-r3-git-20261001b`**。它已包含「尚未設定瀏覽器助手也能開文字聊天室」的修正。

首次安裝用 `Setup-K.ps1`；指定版本更新用 `Update-K.ps1 -Ref 'k-r3-git-20261001b'`。更新前先在 K 選「離開並停止 K」，不要只關閉視窗。更新會先準備、建置與測試新版，成功後才替換程式，不強制停止執行中的工作，也不搬對話或登入資料。

### 退回上一版程式

同樣先「離開並停止 K」，再執行 `Update-K.ps1 -Rollback`，完成後重新啟動。

**程式退版只退程式與啟動器，不把對話還原到以前的狀態。**

詳細步驟與所需環境見 [Git 安裝、更新與退版指南](docs/git-install-update.md)；需要協助時，可請 AI 依這份指南處理。

## 已知限制與使用決定

### 目前不提供

以下是**尚未設計的功能，不是功能做壞**；有實際需要時再個別設計，不先列為必做項目：

- **歷史回溯**：把對話退回先前某一步。查看舊訊息或接續舊對話不等於回溯。
- **檔案還原**：把工作檔案恢復成先前版本。
- **即時語音對話**：與 AI 連續語音交談；目前只有聽寫成文字。

### 封存與資料

**封存＝放棄。** 不要把封存當成備份；K 不提供封存對話的資料備份或還原服務。程式的可退版版本也不是對話備份，需要的內容請在封存前另行保存。

### 語音與新電腦

- 現行本機 Whisper 需要 **NVIDIA 顯卡**、相容的 CUDA 環境、Python 與模型檔，不是可直接搬到任意電腦使用的套件。
- 是否改用 **Windows 內建語音**，待另一台電腦實測後再決定；目前尚未切換。
- 沒有準備語音環境，仍可使用文字聊天室。Git 版本不包含語音模型或本機登入資料。
- 東區那台的 Windows 10 安裝、本人登入、Chrome 助手、真麥克風與剪貼簿操作仍需在當地驗收；本機測試通過不等於已驗證另一台電腦。
