# K HARNESS

**K 執行中樞｜通用工作台**

K 是供個人使用的 AI 工作台。你在同一個介面交代工作、查看結果、處理核准與停止工作；背後由 Codex、Claude Code 或 Antigravity 三個原生核心執行，沿用各自的官方訂閱與權限，不另改走 API 計費。用途是一般文件、資料與程式工作，不接入病歷或 CaseAgent 正式流程。

## 現在能做什麼

- **交代與接續工作**：選擇工作資料夾、新建或接續對話，附上檔案、查看回覆。可切到另一個聊天室討論，不會因此停止原本的工作。
- **處理檔案與程式**：依你的要求與核准範圍，讓 AI 讀取、建立或修改檔案、執行命令；查看成果、預覽與下載。
- **選擇主代理與子代理**：主代理可選 GPT／Claude／Gemini，各自跟隨原生程式提供的模型清單；Gemini 包含目前可用的 Flash 與 Pro，不預先列入尚未提供的模型。子代理有 GPT-6.1 Sol、GPT-6 Luna，以及使用 Antigravity 訂閱的 Gemini 3.8 Flash。南區正式版已接通 GPT／Claude 派 Flash，見[實測與部署紀錄](docs/flash-deploy-claude-review-20261003.md)，由主代理逐項選擇 low／medium／high；需要另外安裝並登入 agy，沒有的話其他功能照常。其他電腦先依[啟用步驟與權限 probe](docs/antigravity-worker-20261003.md#南區其他電腦啟用步驟)驗證。GPT 子代理新對話預設由 AI 選擇模型與推理程度，也可手動指定。K 不為「AI 自動選擇」另做品質評估或調校；在意這件事時，請手動指定。
- **瀏覽器協作**：設定 K 瀏覽器助手後，AI 可在 K 專用 Chrome 操作網頁，必要時由你接手登入或驗證。沒有設定助手，也能正常使用文字聊天室。
- **語音輸入文字**：東區 Windows 10 使用已安裝的 Windows 繁體中文語音辨識引擎；原開發機可沿用本機 Whisper。按聽寫開始，停止後將文字放入草稿，由你確認再送出；取消會保留原草稿。這不是即時語音對話。
- **保留必要控制**：工作失敗、額度、登入、核准與需要你決定的訊息會顯示；工程細節留在後台。可停止工作，也可使用右鍵複製、貼上等文字編輯操作。

不同供應商的能力不完全相同，K 不把其中一家的功能說成三家都有。模型或額度出錯時，不會暗中換模型或重送工作；權限仍以你的選擇與原生核准為準。

Gemini 需要另外安裝 Antigravity CLI（agy），首次開啟需完成官方初始化，再由本人在官方程式開啟的外部瀏覽器登入；Chrome 為預設瀏覽器時會開 Chrome。在 K 的「設定 → 帳號連線」按「新增 Gemini 帳號」，由本人完成官方登入；若要求手機／QR 驗證，請一併完成。關閉官方 Antigravity／agy 視窗後，回 K 按「登入完成，保存帳號」。設定會列出保存的帳號，側欄與額度視窗顯示官方 5 小時／每週剩餘額度。K 不讀取 Chrome 登入資料或接收 Google 授權碼。Gemini 的「工作區編輯」只允許工作區寫檔，命令與額外寫入直接拒絕；若要授予完整能力，需明確選用「完整存取權」。南區正式版支援文字、文件與已驗證的 Gemini 3.8 Flash 圖片；K 瀏覽器助手已接線，但 Gemini 的真 Chrome 操作仍待驗收；Gemini 主代理的跨供應商派工尚未接入。開發完成不等於兩台電腦都已更新，最新驗證及部署界線見[南區部署紀錄](docs/flash-deploy-claude-review-20261003.md)。

## 怎麼啟動、更新與退版

### 啟動

使用既有桌面捷徑開啟 K；或在 K 安裝資料夾執行 `Start-K-Desktop.ps1`。第一次在新電腦使用，需要本人登入官方訂閱並選擇本機工作資料夾，不搬另一台的登入資料。可直接在「設定 → 帳號連線」登入 GPT／Codex、Claude，或開啟 Gemini 官方登入，不必先新增對話；新對話也保留同一組登入入口。

### 安裝與更新

目前更新來源使用 **`origin/main`**，包含訂閱登入、官方登入頁開啟、工作列品牌及可選的 Windows 聽寫。舊標記 `k-r3-git-20261001c` 保留供版本追溯。**南區這次 GPT／Claude 派 Flash 與多帳號介面的更新僅在本機，尚未推上 GitHub；其他電腦從 main 安裝不會取得這批改動。**

首次安裝用 `Setup-K.ps1 -Ref 'origin/main'`，並指定本機官方核心路徑；既有安裝先取得 Git 更新，再用 `Update-K.ps1 -Ref 'origin/main'`。`git pull` 只更新來源，執行更新器才會替換實際使用的 K 程式。更新前先在 K 選「離開並停止 K」，不要只關閉視窗。更新會先準備、建置與測試新版，成功後才替換程式，不強制停止執行中的工作，也不搬對話或登入資料。

### 退回上一版程式

同樣先「離開並停止 K」，再執行 `Update-K.ps1 -Rollback`，完成後重新啟動。

**程式退版只退程式與啟動器，不把對話還原到以前的狀態。**

詳細步驟與所需環境見 [Git 安裝、更新與退版指南](docs/git-install-update.md)；需要協助時，可請 AI 依這份指南處理。

## 已知限制與使用決定

### 帳號

K 可以同時連接 GPT、Claude、Gemini 三家訂閱。GPT／Claude 目前仍各用一個登入；Gemini 可直接新增帳號，登入後保存於這台電腦，並逐帳號顯示登入與額度。**四個真實帳號已保存，免重新登入切換、官方額度與 K 帳號畫面均已實測**，南區 K 已回原帳號並重開。真實額度不足後的工人接手尚未完成驗收，目前進度見[新增帳號與實測紀錄](docs/gemini-login-flow-20261003.md)。

尚未加入帳號時，Gemini 照常沿用目前 Antigravity 登入。加入後逐個帳號使用，共用專案設定，不合併額度，也不讓不同帳號同時工作；官方程式必須關閉才能由 K 協調。工人額度用完後，要先確認停止，再由主代理檢查成果，以新工人接續剩餘工作，不重播整份任務。真實帳號操作須本人登入；多項 Gemini 工作同時開始時，仍可能有一項因帳號狀態確認中而無法開始；這項限制尚未修正，不會自動重送，詳見[驗收界線](docs/flash-deploy-claude-review-20261003.md)。

官方額度查詢偶爾無法確認時，畫面會保留並標示上次資料，可按「刷新目前帳號額度」重新確認，不代表一定要重新登入。

新增帳號前，請先等 Gemini 工作停止並關閉官方 Antigravity／agy。已有原帳號時，「取消新增」會回原帳號；原本未登入時，取消只取消加入 K，不會替你登出剛完成的官方登入。第一次加入帳號後，舊的未綁定帳號 Gemini 對話需開新對話交接；不搬原生歷史，也不動 Chrome 的 Google 登入。

### 目前不提供

以下是**尚未設計的功能，不是功能做壞**；有實際需要時再個別設計，不先列為必做項目：

- **歷史回溯**：把對話退回先前某一步。查看舊訊息或接續舊對話不等於回溯。
- **檔案還原**：把工作檔案恢復成先前版本。
- **即時語音對話**：與 AI 連續語音交談；目前只有聽寫成文字。

### 封存與資料

**封存＝放棄。** 不要把封存當成備份；K 不提供封存對話的資料備份或還原服務。程式的可退版版本也不是對話備份，需要的內容請在封存前另行保存。

### 語音與新電腦

- 東區 Windows 10 使用 `Setup-K.ps1 -Ref 'origin/main' -DictationProvider windows` 設定 Windows 內建繁體中文（臺灣）辨識，不需 Python、Whisper 或 NVIDIA。安裝與驗證狀態見 [東區紀錄](docs/dongqu-install-20261002.md)。
- 現行本機 Whisper 需要 **NVIDIA 顯卡**、相容的 CUDA 環境、Python 與模型檔，不是可直接搬到任意電腦使用的套件。
- 聽寫來源由各台電腦獨立選擇，存在本機設定；未設定時預設 Whisper，更新會保留既有設定，南區不會因取得程式更新而自動切換。
- 沒有準備語音環境，仍可使用文字聊天室。Git 版本不包含語音模型或本機登入資料。
- 東區那台的 Windows 10 安裝、本人登入、Chrome 助手、真麥克風與剪貼簿操作仍需在當地驗收；本機測試通過不等於已驗證另一台電腦。
