# 2026-10-07 手機聽寫與隱藏功能盤點

## 本人要求與範圍

本人發現手機 K 沒有聽寫後明確要求實作，並詢問隱藏項目。接回主輸入與引用註解的麥克風；不是即時語音對話。不增加付費 API、雲端語音或套件，不讀原錄音專案的錄音／逐字稿，只沿用已設定的辨識程式與模型。

## 最小實作

- `frontend/voice-composer.jsx`：遠端與 Electron 共用現有 PCM/WAV 錄音與本機辨識路徑。手機取本身麥克風，經目前私人 HTTPS 把 WAV 送回電腦。遠端 AudioContext 採裝置預設取樣率，既有編碼器轉 16 kHz／單聲道／PCM16。不走 Web Speech。
- `src/remote-access.mjs`：只增加 `POST /api/dictation/transcribe`；保留 Tailscale 身分、Cookie、同源、X-K-Request、持久操作 ID 防重送及五分鐘／16 MiB 上限。
- `src/desktop-server.mjs`：遠端錯誤不含主機診斷路徑；沿用斷線 abort 與既有單筆辨識鎖。
- `frontend/main.jsx`／`frontend/mobile.css`：恢復主輸入與引用註解聽寫入口。手機不提供「轉錄後直接送出」；停止只填入草稿，由本人另按送出。
- 手機退到背景、取消、切換對話會停止本次收音／取消轉錄，既有草稿保留；不把結果貼入別的聊天室。桌面原生聽寫與一般本機網頁 Web Speech 同意流程不變。
- 真瀏覽器測出引用清單被 mobile composer overflow 裁掉，導致麥克風無法點擊；手機引用清單改為輸入區內聯、限高且可捲動。未另建浮層框架。
