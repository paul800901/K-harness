## 根因

原帳號清單保留上次查詢，未使用帳號一律標 stale；設定刷新與額度視窗只查目前帳號。主代理 gemini_accounts 也只讀 list，因此容易把過期百分比當現在可用性。額度視窗原本忽略 HTTP 結果與錯誤，只依賴狀態串流。

曾初步懷疑 HTTP 的 managed usage(false) 丟掉手動刷新，但沿呼叫鏈讀回後確認 unified controller 已將 true 傳到 Gemini；沒有改該路徑或增加第二次強制查詢來冒充根因修復。
