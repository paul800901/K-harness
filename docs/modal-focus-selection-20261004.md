# 對話視窗焦點框與拖曳選字（2026-10-04）

## 使用者看到的問題與根因

- 新對話的工作區選單、重新命名輸入框等，選取時的粗焦點框被裁掉。前一批將標題／X 與捲動內容分開後，共用 `.modal-body` 的 `overflow:auto` 沒替向外延伸 4 px 的焦點框留空間；不是各選單各自損壞。
- 在重新命名輸入框拖曳選字，到視窗外放開會整個關閉。原本只看 click 的最終位置；瀏覽器將跨邊界拖曳的 click 派到 dialog，誤判為點背景。

## 最小修正

- `frontend/style.css`：共用內容區留 5 px padding，配對負 margin 保留原內容位置／寬度，並加同值 scroll-padding，讓鍵盤焦點自動捲動時也保留外框。4 px 外框另留 1 px 給縮放的次像素捨入。沒有移除焦點提示、改成所有內容不裁切或改動固定標題／X。
- `frontend/main.jsx`：只記錄本次指標是否從背景按下，結束 click 也在背景才關閉；從輸入框內開始的選字，以及從背景拖回內部，都不關閉。X、取消、Esc、真正的背景點擊仍有效。不改選字、複製、儲存或工作區功能。
- `test/modal-focus-ui-probe.mjs`：既有真建置介面配假 API 的回歸測試，不用本人聊天室／登入，也不讀寫系統剪貼簿。
