# 手機主畫面入口、記住登入與介面整修（2026-10-07）

## 目標與邊界

本人要求私人手機直接進入 K、不再每次輸入金鑰，並由 Astra、真正 Opus 5.5 與 Gemini 討論、逐頁操作截圖改善手機介面。採現有可加入主畫面的網頁 App，不另建 APK、WebView 核心或常駐服務；工作仍在同一台電腦及原生對話執行。安裝至主畫面與實機驗收另記，不能把 manifest 或模擬截圖當成已安裝。

不把金鑰寫進程式、APK、URL、localStorage 或公開 Git；不開 Funnel、不改三家訂閱／帳號，不恢復暫停的翻譯目標，不重送已知或未知工作。原手機金鑰保留。這次由舊記憶體登入切至持久登入，更新後舊登入須重新配對一次。

## 實作

- `src/remote-access.mjs`、`src/desktop-server.mjs`：Secure／HttpOnly／SameSite=Strict 的 `__Host-k_remote` Cookie，365 天期限，持續使用時最多每天續期一次。電腦只存 session token 的 SHA-256，原金鑰仍只用雜湊核對。
- 同目錄 `remote-sessions.json` 原子保存登入與已接受的操作 ID；**先保存再 dispatch**。程序重啟不忘記已接受的 ID，不重播结果或失敗工作。登出、改金鑰／登入身分或停用會撤銷；存檔失敗回 503、不執行操作，續期失敗不阻止已授權唯讀查詢。
- `frontend/main.jsx`、`mobile.css`：兩列緊湊標頭、短輸入區，模型／權限／推理放在綁定來源對話的底部「對話設定」。保留原生權限確認、明確送出與停止；切換對話會關閉舊設定。
- 側欄收窄並有關閉入口；成果用全頁，模型／權限／目標／設定用底部彈窗；主要觸控控制 44 px，程式碼／表格局部捲動。修正重複成果名稱與收合鈕。
- `appearance.jsx`：手機保留對話字體與主題，隱藏無效的整體縮放控制。字體遵守使用者設定，不強制覆寫成固定小字。
- `worker-activity-popover.jsx`、`work-status.jsx`：手機子代理摘要縮短，未知／久未回報仍保留；換行文字與首行對齊。沒有把安靜解釋成卡死或逾時失敗。
- `test/remote-remember.test.mjs`、`remote-access.test.mjs`、`mobile-remote-ui-probe.mjs`：登入／重啟／撤銷／寫入失敗／跨重啟防重與手機操作回歸；probe 使用獨立測試連接埠，不占正式入口。

## 已知限制

- 持久操作 ID 隨使用量成長，個人低頻使用採簡單檔案；不加任意數量上限而重新放行舊 ID。注意已讀／搜尋也會寫 ID，不能以每天 100 次估算保證效能；有實際瓶頸再處理。
- 設定讀取失敗會 fail-closed 並撤銷登入；初始存檔損壞／過濾回寫失敗需修正後重開。停用時清除登入存檔失敗可能連本機啟動都受阻。這些為 Opus 的非阻擋 P3，未增加新的復原系統。
- 小於 500 px 的低視窗隱藏頂端狀態列，斷線告警及重要工作提示仍在；不是完整橫向操作驗收。
- 主畫面 App 仍需要手機 Tailscale 連上同一私人網路、電腦 K 正在執行。選「離開並停止 K」仍會讓手機離線；不能靠圖示使關機的電腦執行。
- 清除手機網站資料／登出／撤銷／期限到期仍需配對，不能保證永不登入。原生 APK、離線工作／推播未實作，也不列為本次必要架構。
