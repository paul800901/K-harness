## 改動與保留

1. **DeepSeek／Pi 全線移除**：終端原型、worker／dispatcher／MCP 登記、工人統計與 UI、npm 指令／相依及僅服務舊路徑的測試與探針。專案 `.codex/config.toml` 改為無 k_flash 登記。舊 job、秘密檔、Git 版本不刪；原生 host 的 disabled k_flash 覆蓋保留，防止其他舊工作區設定又載回已移除路徑。
2. **Sandboxie 執行碼移除**：pool/process/control/stdio/workspace、isolated provider factory 與非原生分支；正式只走原生 host/spawn。歷史路徑名稱仍保留，避免搬動 CODEX_HOME、CLAUDE_CONFIG_DIR、對話及 Chrome profile。Windows Sandboxie 元件與舊實驗資料不碰。
3. **內嵌瀏覽器與 standard 舊入口移除**：Electron browser views/CDP/下載代理、legacy web、裸 state 分支、舊 Win+H 與無呼叫者探針。保留 Electron 工作台、外部 Chrome 擴充／native messaging、MCP、下載的 Zone.Identifier、本機 Whisper 與原生媒體權限。系統匣只走原生入口，重建 C# 啟動器。
4. **GPT 子代理選擇**：新對話可選 GPT-6.1 Sol／GPT-6 Luna 及官方支援的 effort，AI 也可在派工時明確選擇。保存並恢復預設；未指定仍 Luna/high。Claude 的 Codex bridge 按需啟動，未派工不多開 Codex。沿用原生訂閱與權限，不加 fallback 或重送。
5. **Sonnet 5.5**：沿用官方模型目錄，不新增硬編碼假模型。2.1.280 回傳 Sonnet 5；官方 changelog 指 2.1.284 加入 Sonnet 5.5，2.1.285 原生 initialize 已實際回傳 `claude-sonnet-5-5` 與 low/medium/high/xhigh/max。主代理仍依人選擇，不改舊聊天室模型。
6. 清掉 Pi 相依後發現 `chrome-extension-context.mjs` 直接 import `ws`，過去靠 Pi 間接安裝；因此明確保留**既有同版 ws 8.21.3**，沒有下載新套件。鎖檔離線產生，並在不含 Pi 的乾淨相依樹重新建置、測試。

保留：R3-1 取消連線／明確退出／確認強制結束、原子寫入、來源聊天室綁定、官方核准、HTTP Host/Origin/token/bootstrap、瀏覽器不搶前景、不自動因人工活動鎖 AI、禁止 API 計費暗換。共享知識仍不納入正式版。
