# 子代理預設由 AI 自動選擇（2026-10-01）

## 使用者決定
新對話子代理預設「AI 自動選擇」，主代理依每個子任務選 GPT-6.1 Sol 或 GPT-6 Luna 與官方支援的推理程度。仍可手動選派工預設，既有對話設定不改。

## 最小實作
- 選單增加自動選項，自動模式不顯示固定推理程度；新對話不繼承上一個聊天室的手動子代理設定。
- 自動政策以 `model:auto, effort:auto` 保存；不把 auto 當作真模型送出。
- Codex 原生派工指示要求逐次明確選模型／推理；自動模式不固定 native default_subagent_model。
- Claude 的派工工具說明提供選擇要求；橋接執行前須有具體模型／推理，才送原生工作。
- 不新增難度分類器、不因錯誤／額度自動換模或重送，不改權限、登入或計費。

## 驗證及部署
- 主代理獨立重跑定向測試 **27/27**；建置 UI 的 headless Edge 實際選單測試通過：預設 auto、手動 Sol/ultra、下一個新對話恢復 auto、送出正確政策，未送模型工作。
- 完整套件 **502/502**（另由主代理落盤重跑）。首次回歸有兩個舊測試仍期待 Luna 預設，已依新需求更新；不是略過失敗。
- 假原生 host 驗證 Sol/ultra 與 Luna/high 逐次選擇原樣送達；自動模式漏選時沒有開始任何工作；舊手動設定與 requestId 不重送保留。
- 尚未消耗真模型回合測主代理的難度判斷品質；以上證明 UI、政策與派工參數接通，不把假 host 當成實際模型判斷驗收。
