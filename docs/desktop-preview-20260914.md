# K 桌面預覽版

## 啟動

桌面入口：`C:\Users\Paulus\Desktop\K HARNESS.lnk`，指向專案 `Start-K-Desktop.ps1`。它啟動隱藏的本機 Node 後端，待健康檢查通過後以 Chrome／Edge 應用程式視窗開啟前端。若沒有這兩個瀏覽器，使用預設瀏覽器。

本機網址：`http://127.0.0.1:47831`。不對區域網路開放，不新增登入、不複製憑證，不安裝套件或改動 DSH。這是本機啟動包，不是可攜式 EXE／安裝程式；依賴本機既有 Node、官方 Codex 與 K 專案。

按「開始新對話」使用所選 Astra／Sol；左側點原對話可接續。切換前須結束目前主回合；切換主控會先查原工人並中止可確認的執行中工作。建立連線本身不送出模型回合。

按「停止工作」中止目前主回合與可確認的工人，保留已寫成果。「查詢」僅檢查工人，不取消或重派。每次核准只適用顯示的那一次請求；不預選、不保留永久許可。

關閉瀏覽器／視窗不會停止後端與背景工作。需要結束整個 K 時，按「停止後端」並確認。下次再點桌面入口。狀態不明時先查原工作，不自動重送。

## DSH UI 的沿用範圍

使用本機 DSH `dsh-v0.1.5-rc.2` 的三份獨立主題樣式：`design-platform.css`、`base.css`、`scrollbar.css`，存於 `web/dsh`，保留 MIT 授權與來源。版面參考 DSH 的左側對話、中間工作區、右側資訊與底部輸入區。

這不是整套 DSH React UI 移植。DSH 的 web boot 依賴 Cordis、`__ModuleLoader__`、外掛 manifest 與 DSH 對話資料；K 沒有引入它們，也沒把主控換回 DSH。自有 K 元件負責接現有 Codex 主控與 Pi 工人。原 DSH 程式、設定及工作資料未修改。
