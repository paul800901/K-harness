# 按需歷史檢索驗收（2026-09-14）

## 實作與操作範圍

`runWorker`、dispatcher、CLI request 及 MCP start 均接受選用 `historyIds`，只授權同一 stateDir、同工作區的明確舊 job ID；預設不提供歷史工具。改變授權不能重用原 request ID。紀錄在新工人啟動前讀成唯讀快照，模型只收到查詢結果，不預先收到全文。

`search_history` 做字面文字查詢，每次最多五筆、每筆最多 4,000 字元，附 jobId、來源行、角色、時間及截斷標記；offset 翻頁。最多 20 個授權 job，每份 transcript 最多 16 MiB，job metadata 最多 1 MiB，超限或無法讀取即拒絕，不默默遺漏。來源必須是受信任主機保存的非敏感紀錄；這不是保密資料自動去識別化、OS 沙箱或對惡意本機程序的安全隔離。

舊任務與工具內容只是歷史證據，不可自行擴張權限。時間較新本身不等於裁決；須找明確更新，衝突或缺漏要回報。尚無跨 job 語意排序、全文片段續讀或自動壓縮；被截斷內容不能宣稱完整讀過。此功能不是所有對話全域搜尋，也不接管主代理記憶。
